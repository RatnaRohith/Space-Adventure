Complete Player Movement Script
extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5

func _physics_process(delta: float) -> void:

    # Apply gravity
    if not is_on_floor():
        velocity += get_gravity() * delta

    # Read player input
    var input_dir = Input.get_vector(
        "move_left",
        "move_right",
        "move_forward",
        "move_backward"
    )

    # Calculate movement direction
    var direction = transform.basis * Vector3(
        input_dir.x,
        0,
        input_dir.y
    )

    # Apply horizontal movement
    if direction:
        direction = direction.normalized()
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)
        velocity.z = move_toward(velocity.z, 0, SPEED)

    # Handle jumping
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY

    # Move character and handle collisions
    move_and_slide()
How gravity works
if not is_on_floor():
    velocity += get_gravity() * delta

is_on_floor() checks whether the character is standing on a floor.

get_gravity() returns the gravity vector configured for the physics body and project.

delta represents elapsed time in seconds.

velocity += ... adds gravity to the current velocity, pulling the character downward.

Why check is_on_floor()? Gravity is applied while the character is airborne, including while jumping or falling. When the character is standing on a floor, gravity is not continually added.

Input setup: In Project → Project Settings → Input Map, create move_left, move_right, move_forward, and move_backward and assign A, D, W, and S respectively. The ui_accept action is commonly mapped to Space for jumping.

Note: This code uses transform.basis, so movement follows the player's orientation. For a typical third-person controller, you may later want to calculate movement relative to the camera instead.
